## Load order
1. Read `README.md` for the social-experiment definition and current operating principles.
2. Follow links to the canonical repository for any subsystem before making technical claims or changes.
3. Load only the artifact, issue, or subsystem evidence needed for the active task.

- Canonical product/runtime truth may live in successor repositories; do not assume the historical implementation remains current.

## Context budget
- Do not scan all historical experiments, media, issues, and generated artifacts by default.
- Prefer current canonical successors and targeted evidence reads.
- Historical artifacts are reference-only unless reconstruction is explicitly requested.

## Human gates

## Stop conditions
Stop when a task depends on a superseded subsystem, canonical ownership is unclear, or historical evidence conflicts with the current implementation source.
