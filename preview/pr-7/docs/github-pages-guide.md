# GitHub Pages 作成ガイド

このページは、限界開発のような入口ページをGitHub Pagesで公開するための最小手順です。

## 1. リポジトリを用意する

公開したいリポジトリの直下に、最低限次を置きます。

```text
index.html
README.md
assets/
```

## 2. index.htmlを作る

最初は次の要素だけで十分です。

- 企画名
- 何をしているか
- 誰向けか
- 実績
- 相談窓口
- GitHubや資料へのリンク

## 3. 画像を置く

画像はHTMLへ直接埋め込まず、リポジトリ内の別ファイルとして置きます。

例：

```html
<img src="assets/hero.jpg" alt="限界開発のトップ画像">
```

画像をBase64でHTMLへ埋め込むと、ファイルが巨大化したり、途中で切れて表示されなかったり、過度な圧縮で画質が落ちることがあります。

## 4. GitHub Pagesを有効にする

GitHubのリポジトリ画面で次を選びます。

1. Settings
2. Pages
3. Build and deployment
4. Deploy from a branch
5. Branchをmain、Folderをrootに指定
6. Save

反映には数分かかる場合があります。

## 5. スマホで確認する

- 画像が表示されるか
- 文字が読めるか
- ボタンが押しやすいか
- リンク先が正しいか
- 横スクロールが発生していないか
- 一番重要な行動が上部にあるか

## 6. 入口ページの推奨順序

```text
企画名・要約
↓
相談または主要行動
↓
何を解決するか
↓
相談後の流れ
↓
実績
↓
詳しい仕様・資料
↓
安全線
```

## 7. よくある失敗

### 画像が出ない

ファイル名の大文字・小文字、拡張子、相対パスを確認します。

### 古い画面が残る

GitHub Pagesの反映待ち、ブラウザキャッシュ、Safariのタブ再利用が原因の場合があります。数分待ち、再読み込みまたはタブを開き直します。

### リンクが404になる

GitHub Pages上の相対パスと、GitHubリポジトリ上のファイルリンクは挙動が異なります。公開用ページはディレクトリ末尾の`/`を意識します。

### 情報を詰め込みすぎる

トップページは入口です。詳しい仕様や再現資料は別のインデックスへ分離します。

## 8. 更新時の確認

- 変更前のファイルSHAを取得する
- 同じファイルを並列更新しない
- 更新後のリンクを実機確認する
- 作りかけ表示を残さない
- 新規資料をインデックスへ追加する
