# Episode 001 — 未対応案件抽出・報告文作成ツール

## 概要

一覧表またはCSVから未対応案件を抽出し、期限状況、担当者別件数、上司向け報告文の下書きを表示する公開デモ用の最小試作品を作ります。

- 配信日：2026-07-31
- シリーズ：限界開発
- 実装方式：単一HTML
- 対象端末：スマートフォン優先
- 使用データ：架空のサンプルデータのみ
- 外部API：使用しない
- 永続保存：行わない

## 今回解決する悩み

一覧表を開き、未対応の案件を手作業で探し、期限を確認し、担当者ごとの件数を数え、上司への報告文を作る作業を減らします。

頻度と1回の所要時間は未確認です。実際の相談者が登壇した場合に確認し、勝手に事実として補完しません。

## 最低成功条件

> サンプルデータまたはCSVから「未対応」の案件だけを抽出し、スマートフォン画面へ表示できること。

## 完全成功条件

- CSVファイルを読み込める
- サンプルデータを読み込める
- 未対応案件だけを抽出できる
- 期限順に並べ替えられる
- 期限超過・本日期限・期限内を判定できる
- 担当者別件数を集計できる
- 上司向け報告文を生成、編集、コピーできる
- 不正な入力へ日本語でエラーを表示できる
- 画面幅320px程度で操作できる
- 外部通信や永続保存を行わない

## 縮退順

時間不足または不具合が発生した場合は、以下の順で削ります。

1. 報告文の再生成
2. コピー機能
3. 担当者別集計
4. 本日期限の分類
5. 期限超過の分類
6. 期限順への並べ替え
7. CSVファイルの直接読み込み

最後まで残す機能は、サンプルデータから未対応案件だけを抽出し、スマートフォン画面へ表示する機能です。

## 安全上の注意

- 実在する会社名、顧客名、個人情報、社外秘情報を入力しない
- 実際の業務ファイルを配信中に使用しない
- 外部サービスへログインしない
- 外部APIへ接続しない
- 自動送信しない
- 本番導入可能と断定しない

## 本番導入前に確認すること

- 実際のCSV列名、日付形式、文字コード
- データ量
- 個人情報・秘密情報の有無
- 利用端末、利用人数
- 保存、権限、バックアップ
- 外部サービス連携
- セキュリティと利用規約
- 運用担当者とエラー時の対応
